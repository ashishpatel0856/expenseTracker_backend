💰 Money Manager Backend – Spring Boot
- **A production-ready Money Manager Backend built using Spring Boot, designed with Clean Architecture, RESTful API principles, and industry-standard security practices.
This backend provides core functionalities including user authentication, income & expense tracking, category management, dashboard analytics, filtering, and secure API access.**

🔐 Authentication & Authorization
- **User Registration**
- **User Login**
- **JWT-based Authentication**
- **Secure Password Encryption**
- **Account Activation via Email Token**

👤 User Profile Management
- **Register new user profiles**
- **Login with email and password**
- **Activate account using token**
- **View and manage profile details**

📂 Category Management
- **Create categories**
- **Update categories**
- **Delete categories**
- **Fetch all categories for current user**
- **Fetch categories by type (INCOME / EXPENSE)**

💸 Expense Management
- **Add expenses**
- **View current month expenses**
- **Delete expenses**
- **Categorize expenses**
- **Track expense history**

💰 Income Management
- **Add income entries**
- **View current month incomes**
- **Delete income records**
- **Categorize income sources**

📊 Dashboard & Analytics
- **View dashboard summary**
- **Monthly income vs expense overview**
- **Aggregated financial insights** 

🔍 Filtering & Search
- **Filter transactions by type**
- **Filter by date range**
- **Search using keywords**
- **Sort by field and order**

📧 Contact & Support
- **Send contact messages**
- **Handle user queries via API**
